# Introduction
Ullmanite is a basic dicom renderer that uses the cube march algorithm to construct a 3D mesh. This project was developed for my ingenering degree. I have experimented a lot with UI interfaces, tree structures, event handlers, graphics api abstractions, SDF and aplication structurization.

## Features
List of features that where implemented

 - Arc and fps style camera for the 3D scene
 - 3 axial cutting
 - Color transfer functions
 - Threshold sampling

 ### Platforms
 The app was build for Windows and tested of Windows 10 and Windows 11.
